# WordPress Projects

A collection of WordPress development projects focused on modern theme development, custom functionality, and hands-on experimentation.

This repository serves as a workspace for building and exploring WordPress solutions using current development practices and tools.

## Projects

### 01. WordPress Project — Embark

**Directory:** [`wordpress-project-embark/`](./wordpress-project-embark/)

A custom WordPress development environment built with Docker, featuring a block-based theme and native Gutenberg functionality.

**Technologies:**
- WordPress
- PHP
- HTML & CSS
- Gutenberg Block Editor
- Full Site Editing (FSE)
- `theme.json`
- Docker & Docker Compose
- MySQL

**Development focus:**
- Custom WordPress block themes
- Global styles and design tokens
- Gutenberg blocks and styling
- Block templates and dynamic content
- WordPress theme architecture
- Local development with Docker
